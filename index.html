判断逻辑（对齐《集合竞价全景分析系统》第五章）：先全市场扫描竞价涨停股，再按行业聚类、以「该行业竞价涨停家数」定级——
· S级（爆发）：该行业竞价涨停≥5只，梯队完整 → 主线确认，可重仓龙头/中军
· A级（强势）：该行业竞价涨停3–4只，龙头强 → 可参与，选最强标的
· B级（脉冲）：该行业竞价涨停1–2只，无梯队 → 只看不做
· C级（弱势）：无竞价涨停 → 回避
✅ 推荐参与 = S级 / A级（即该行业竞价涨停≥3只）——不是「涨得多就算」，避免把一堆 +1% 的板块都标成可参与；无主线（前3行业占比<40%）时按铁律⑦轻仓。
数据说明：读取东方财富实时行情。集合竞价时段（9:15–9:25）的涨跌幅即真实竞价价；其余时段为最新实时行情，仅供验证逻辑。铁律：9:20 前可撤单为「演戏」，竞价强≠全天强，9:30 后须第一笔成交验证。
辨识度评级、生命周期阶段、涨停基因打分、主力资金参与度均基于个股 K线 / 均线 / 量能 / 成交额 / 流通市值 / 板块热度等真实数据计算；解禁减持与部分财务合规数据未接入（报告中已逐项标注，分数偏保守）；大盘情绪周期、板块 S/A/B/C/D 分级需外部数据补充。
