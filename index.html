判定口径（对齐《板块爆发后低吸选股策略》· 全部可核对）

      

        选股范围：只从涨停股里选（涨停=资金用真金白银投票），不从几百只成分股里找。

        分层：中军（首选，流通市值 100–300 亿 + 板块成交额前 3 或市值前 20% + 换手 3–20% + 10:30 前涨停）> 核心标的（50–150 亿 + 首板/二板 + 换手 5–15% + 10:30 前涨停）> 趋势龙（MA5>MA10 多头 + 斜率向上，仅观察）。

        排除（直接删）：14:00 后涨停、换手 >25% 天量、一字板（换手<3% 且未开板）、≥3 板纯情绪连板、股价 >50 元、流通市值 <30 亿、近 6 个月已走过 ≥5 连板、MA5 向下且连续破线≥3 天。

        买点（不是第二天竞价）：爆发日不买 → 第 2–3 天首次分歧缩量回调到 MA5 附近才低吸；缩量跌是洗盘，放量跌是逃命。

        缩量比口径：涨停日之后（调整期）均成交量 ÷ 涨停日之前 20 日均成交量，<0.7 视为合格洗盘。若「数据日期=最新交易日」，说明该股今天才涨停，还没有调整期 → 缩量比显示「—（爆发日无调整期）」，按策略当天不买。

        止损：中军有效跌破 MA10 离场；核心标的有效跌破 MA5 离场；通用单笔 −5% 无条件止损。

        数据源：东方财富涨停池（首次封板时间 / 连板数 / 炸板次数 / 换手率 / 流通市值 / 成交额 / 封板资金 / 所属行业）+ 个股日 K（MA5/10/20、近 6 个月连板记录）。

        未接入、需你自己确认的项：题材正宗度（核心业务占比）、机构是否参与、近 6 个月减持公告、ST/退市风险（ST 已在数据源侧剔除）。这几项本工具不做判定、不猜，请在入选后人工核对。

        旧版曾按「占涨停幅度的比例」归一化（0.15 / 0.40 / 0.70），会把 ST 股 +1.97% 放大成「中阳」、把涨停的新股判成「大阳」，已废弃。

        涨停判定：10cm 主板 9.8% · 20cm 创业/科创 19.8% · 30cm 北交所 29.7%（距阈值 0.3% 内即算）。ST 自 2026-07-06 起沪深主板已由 ±5% 放宽为 ±10%（《交易规则(2026 年修订)》），与主板同档、不再单列。

        今日路径：按「昨日档位 → 今日路径」矩阵判定，风险路径优先（先判放量下跌/破位/长上影，再判机会路径），每张卡片标注命中的矩阵编号（S/M/L/Y/Z/D）。

        「小阴洗盘→小阳收复」三分情形（补充项）：昨日浅阴（跌幅 < 0.25×涨停，如 -1.8%，属上涨途中的小喘气）+ 今日小阳完全收复（涨幅 ≥ 昨日跌幅）→ 强势整理（Y9/Y10/Y11），按「量能 × 位置」分：A 缩量·非高位 = 洗盘结束（持有，回踩 MA5 低吸） · A′ 放量（既非低位也非高位）= 分歧/抢筹，不等同 A 的"缩量健康换手"（持有观察，冲高先减、等缩量回踩） · B 低位 + 放量≥1.5 = 企稳修复确认（小仓低吸 ≤2成） · C 高位 = 滞涨（缩量=萎缩不涨 / 放量=放量滞涨，均不加仓、准备止盈）。对照：昨日深阴（≥0.25×涨停，如 -3%）今日只是打平 → 属「阴阳对冲·弱修复」（Y6~Y8），修复质量低于本条。

        量能倍数：今日成交量 ÷ 昨日成交量（量口径，不是额口径；价差大时两者会有偏差，此处如实标注）。文档的「1.1~1.6 倍」等阈值为经验值，直接采用。

        位置过滤（补充项）：文档的多处买点（两阳缩量、两阳夹一阴、弱转强）都要求「必须在低位/上升趋势中途，不在高位」——本工具用 60 日区间位置补上这一条：位置 >80% 时判为高位，机会信号一律降级并提示「高位陷阱」。

        分时维度：用当日 5 分钟 K 线算均价线（VWAP）——收盘价在均价线上方/下方、均价线方向、在均价线下方的时间占比。数据源不可用时该维度不参与判定并在卡片上写明（不猜）。

        矩阵补全（2026-09-19 修正）：部分单元格原用绝对涨跌幅做阈值（如"今日 >2%""|涨幅| ≤1.5%"），对 20cm / 30cm 这类涨跌幅限制不同的标的会产生空档，个别股票显示「未匹配到矩阵单元格」。现已统一按市场通用绝对口径判档，并补齐 S6–S10 / M10–M12 / L10–L11 / M13 / L12 / Y13 / Y14 / X3 / Z7 等缺失单元格：全组合矩阵（10cm / 20cm / 30cm × 8 个昨日档 × 8 个今日档 × 量能档）已无空档，且涨停日一律按「涨停」定性（不再被"实体够大"降级成「大阳确认」）。

        数据缺口（不判定、需你人工确认）：大盘情绪周期的六个阶段、板块 SABCD 分级（工作台的竞价分级口径是 9:25 竞价涨停家数，与全天口径不同）、连板晋级池与晋级率、竞价量比（历史竞价数据未存）。这几项本工具不做判定，只用「退潮/冰点」手动闸门代替大周期过滤的第一层。

判定口径（8 个维度 100 分 · 全部可核对）

      

        输出两件事：① 状态 —— 主升浪进行中 / 主升浪启动 / 启动前夜（蓄势）/ 主升浪走弱 / 高位出货风险 / 尚未启动；② 信号共振度（0-100 分） —— 文章说「单一特征出现启动概率不足 30%，多重共振才高」，所以分数就是「命中了多少条特征」。

        八个维度与权重：位置与结构 12 · K线与形态 24 · 均线与趋势 18 · 量能 18 · 缺口 8 · 技术指标 12 · 换手与筹码 6 · 涨停基因 2。

        状态判据（风险优先，命中即停）：

        ① 高位出货风险 = 高位（距 250 日低点 >150% 或偏离 MA60 >45%）且出现 放量滞涨 / 换手 >15% / 长上影 / 有效跌破 MA10；

        ② 主升浪走弱 = 连续 2 日收在 MA10 下方且 MA5 走平/向下（且 MA20 仍在 MA60 上方）；

        ③ 主升浪启动 = 突破型大阳（实体 ≥3%、上影 ≤30%、量 ≥1.2 倍）站上 MA20/MA60，或带量（≥2 倍）突破前 60 日高点；

        ④ 主升浪进行中 = MA5>MA10>MA20>MA60 且站上 MA10 且 MA5 向上，并且均线已向上发散（MA5 至少高出 MA60 的 2% —— 否则基座里均线缠绕，一根阳线就会让排列「看起来」是多头）；

        ⑤ 启动前夜 · 蓄势 = 底部收敛（40 日振幅 ≤15%）+ 均线粘合（≤5%）+ （连阳 ≥4 或 长下影 ≥2 或 低点抬高 或 未回补缺口）；其余为尚未启动。

        「近 20 / 120 日内出现过即可」的项：底部横盘、突破型大阳、倍量、暖气带 —— 因为文章讲的是「主升浪启动前一定出现」，所以按回顾窗口计分，已经走完启动段的票不会因为「特征过期」而掉分。

        算法全部纯计算：MACD（EMA12/26/DEA9）、RSI6/14、KDJ(9)、5/10/20/30/60 日均量、日线合成的周线（5/10/30 周均线 + 周 MACD）、未回补向上缺口、试盘/揉搓线形态、筹码近似（近 120 日价格区间成交量分布 → 单峰密集度 + 上方套牢盘占比）。

        未接入、需你人工确认：Level2 大单占比 / 逐笔主力净流入方向、真实筹码分布数据（此处为近似）、财报与赛道拐点（业绩止跌回升、政策利好）、月线 RSI（K线长度不足 15 个月，已用周线代替并标注）。这几项不参与打分。
